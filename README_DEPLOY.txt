PURPOSE PV — CLOUDFLARE PAGES DEPLOYMENT

Contents
- index.html: bilingual English/Spanish website
- robots.txt: crawler instructions
- sitemap.xml: homepage sitemap

Before deploying
1. This is a standalone static website package.
2. It includes page title, meta description, canonical URL, social metadata and Restaurant structured data.
3. The website uses text-based PURPOSE wordmark styling; it does not bundle the original logo or dining-room photograph.
4. Confirm you are deploying to the existing purposepv.com Cloudflare Pages project.

Cloudflare Pages Direct Upload
1. Open the existing Pages project in Cloudflare.
2. Choose Create deployment / Upload assets (wording may vary).
3. Upload the ZIP contents with index.html, robots.txt and sitemap.xml at the root level (do not upload an extra enclosing folder).
4. Deploy, then test https://purposepv.com/ on mobile and desktop.
5. Check /robots.txt and /sitemap.xml after deployment and submit the sitemap in Google Search Console if needed.

Important
A new Pages deployment can replace the files in the current deployment. This package is self-contained and does not rely on your previous assets folder, but it does not include the original Purpose logo or dining-room photo.
